# 计算机网络 · 12个学习日

基于[阿秀的学习笔记](https://interviewguide.cn/)计算机网络专题，面向零基础学习者重新组织的图文课件。每天约90分钟、每周学习6天，共两周。原站正文编号1–104，加一条补充题；105个条目全部关联到课程知识点。

## 打开课件

- **默认入口：[index.html](index.html)**。正式学习按天解锁；首次打开从第1天开始，已有记录则继续原进度。
- **检查入口：[review.html](review.html)**。开放全部12天，使用独立检查记录。

完成当天5道自测的作答与自评、勾选3项收尾检查，再点击“标记本日完成”，即可解锁下一天。检查记录与正式学习记录分开。更新课件保持原课程及记录标识，不主动清空正式学习记录。

全部47个课程知识点均提供图示交互：参与方连线、字节区块或数值曲线按机制分别表达。除保留的ARP演示外，其余46项各有两种比较情形，可逐步查看和重新演示；图示条件和参考资料可展开。

两个入口均为自包含HTML。拉下仓库后，用浏览器直接打开，不需要安装开发依赖，也不依赖原电脑。网站知识点和参考文献链接需要联网。

## 换电脑继续学习

1. 在另一台电脑clone本仓库，之后用pull获取课件更新，打开 `index.html`。
2. 在当前浏览器点击页尾“导出学习记录”，将导出的JSON带到新电脑，再点击“导入学习记录”。编写检查导出 `network-course-review.json`；正式学习导出 `network-course-study.json`，包含已解锁进度、作答、自评、知识点笔记和分段用时。两种记录分别使用。
3. Git同步课程代码，不会自动同步浏览器记录。记录保存在本机浏览器，建议在换电脑和清理浏览器前导出。个人记录不提交到Git。
4. GPT对话与本地文件访问是另一层权限。继续已有聊天，或在新电脑把clone下来的文件夹设为本地项目；需要时导出本课交接文件，交给GPT后继续答疑。

[官方OpenAI文档](https://learn.chatgpt.com/docs/projects)明确区分聊天同步和项目文件访问。不能仅凭登录同一账户保证另一个聊天可读取本地文件。

## 学习与答疑

- 学习模式折叠两侧栏，保留可暂停的计时器；环节分类由你手动选择。
- 每个知识点有独立笔记，支持复制粘贴并自动保存在当前浏览器。
- 每天开头显示全部关联网站知识点，知识点开头显示该节对应条目；链接直接定位到原站题目。
- 点“这里还没懂”生成带知识内容、网站知识点链接和当前笔记的问题上下文，复制到聊天中。
- “导出本课交接”生成Markdown，包含当前课程内容和你的笔记、作答，适合另一台电脑或没有项目文件访问权限的聊天。

## 项目结构

```text
lessons/lesson-01.html … lesson-12.html  原有课程正文
interactive-examples.json               全知识点的基础解释、对比例子和分步图示数据
diagrams.js / lesson_examples.py        交互显示与构建验证
curriculum.json                         顺序、网站知识点与正文锚点
state.js                                解锁与学习记录校验
app.js                                  课程显示、计时、笔记与交接
style.css / template.html               共享界面与模板
build.py                                校验并生成两个自包含入口
tests/state.test.cjs                     进度与记录测试
docs/                                   当前需求、维护与跨电脑说明
```

修改源码后运行：

```sh
python3 build.py
python3 build.py --check
node --test tests/state.test.cjs
```

`index.html` 和 `review.html` 是构建产物，纳入仓库以便直接学习；不直接编辑它们。`template.html` 误开时会跳到默认入口。

`curriculum.json` 的 `default_mode` 为 `study`，默认入口按天解锁；`review.html` 始终全部开放。

## 开发说明

当前为完整课程开发交付，不维护旧样稿记录格式。检查模式与正式模式使用不同记录，不会互相解锁。正式学习的解锁是学习节奏安排；内容已随HTML提供，并非权限或保密机制。

上传前检查当前文件和Git历史，排除凭据、个人记录、临时资料和预览截图。本仓库不需要API密钥，也不包含GPT接口调用。公开仓库不等于对第三方参考资料取得额外授权；网站知识点通过链接引用，讲解为重新组织编写。
