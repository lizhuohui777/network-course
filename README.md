**学习时请打开 [index.html](index.html)**：包含12个学习日的课程规划、全部原题映射和第1天交互课件。第2–12天目前只有规划，待第1天实测校准后制作。

## 已确定

- 零基础；两周、每周6个学习日和1个休息日，共12个学习日，每日90分钟。
- 目标：建立框架、解释核心概念、串联一次网页访问、回答基础情境题。
- 原站正文实际为编号1–104，加1道补充题；第80题跨页重复。所有105个条目都有课程位置，重复概念合并教学。
- 原题是覆盖范围，不是讲稿。采用原创图文、具体例子、必要前置解释、机制推演和自测；事实错误或版本差异使用第一方来源核实。
- 每天一个主题，按难度安排题量，不固定10道原题。低频内容先认识，核心内容要求理解并用于简单场景。

## 如何开始或继续

本会话可直接说“第1天的端口我没懂”。新会话使用：

> 继续这个 network-course 项目。先读根目录的 AGENTS.md、learner-state.json 和课程维护约定.md，再接着教我。

这些记录保存于本地项目。新会话需要访问本目录后才能读取记录，静态网页不会自动读取会话。原ChatGPT项目的同步参考资料保持只读，不作为本项目可编辑源码。

## 课程文件

- `index.html`：自包含的浏览器课件，离线可用；来源链接需联网。
- `课程维护约定.md`：时间控制、内容深度和会话答疑后的更新流程。
- `curriculum.json`：12天安排、逐题映射、来源和版本。覆盖不代表已经学会。
- `learner-state.json`：仅记录用户明确报告的学习情况；浏览器计时和自测不会自动同步到该文件。
- `CHANGELOG.md`：已发布修改及原因。

## 学习模式与笔记

课件顶部的“学习模式”收起两侧栏，保留可暂停的计时器。每个知识点标题旁的“笔记”打开该知识点的独立记录；支持复制粘贴文本，输入后自动保存在当前浏览器。笔记随学习记录一起导出、导入，不会自动同步到聊天或项目文件。

“计时归类（手动）”只决定之后的用时计入哪一类；切换时结算上一段，不自动判断阅读位置或切换课程。刷新后保留归类与学习模式设置，计时保持暂停。

## 修改课件

共同模板在 `template.html`、`style.css` 和 `app.js`；第1天正文在 `lesson-01.html`。修改后在本目录运行 `python3 build.py`，重新生成 `index.html`。只维护一份正文和模板；生成文件不直接编辑。

浏览器记录保存在当前浏览器中，可用页内“导出学习记录”备份；换浏览器或清理存储后，可导入恢复。同一浏览器的 file:// 存储行为可能因设置变化，重要记录请导出。课件版本更新保持课程ID、题目ID和原有记录键稳定。
