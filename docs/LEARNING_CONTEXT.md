# 接续这套课件

学习者为零基础，计划两周学习12天，每周6天、每天90分钟。目标是建立网络知识框架，解释核心概念并用于简单场景。课件需充分图文、具体例子和逻辑联系，同时避免制作旁白和重复提醒。

全部正文位于 `lessons/`，顺序与105个网站知识点映射位于 `curriculum.json`。每天包含回忆检查、今日主线、五道理解自测、三项收尾检查。每个 `.topic` 有稳定ID、网站知识点关联和独立笔记。

当前仍在编写检查：默认入口 `index.html` 和 `review.html` 都开放全部12天，共用检查记录。检查完成、用户要求正式学习后，才将 `curriculum.json` 的 `default_mode` 从 `review` 切换为 `study` 并重建，令默认入口按天解锁。检查记录不能当成正式进度。当前没有任何实际学习完成或掌握度报告，不应因为内容已写好就认定学习者学过。

换电脑：GitHub clone/pull携带代码和HTML；浏览器笔记、进度通过JSON导出/导入；GPT聊天历史与本地文件权限另行处理。不能承诺同账户自动同步本地文件或浏览器数据。

新聊天可用：

> 请先读这个项目根目录的AGENTS.md和docs/LEARNING_CONTEXT.md。我在学习第N天，请基于lessons/中的课件回答问题；先讲清，再主动提出是否补进课件。

若聊天无法读取项目目录，将课件页尾“导出本课交接”所得Markdown提供给它。该文件可能包含个人笔记和作答，由学习者决定提供给哪个聊天。文件与源代码不会自动互相读取或发送。
