# 本地教学修订审查

日期：2026-11-15。基线：已发布提交 `3ac5dea`，版本 1.1.1。用户已授权提交、推送独立分支并创建PR；主分支合并须另行确认。

## 教学检查

一位写作者统一修改正文与图示；一位独立复读者先检查原课件，再按第1至12天顺序复读实际修改文件。覆盖47个课程知识点、105个网站知识点、昨日回顾和60道自测，不以作者摘要或程序测试代替阅读验收。

- 第1–3天：同机服务入口放进同一设备范围，TCP正文与图示统一HELLO/WORLD，UDP先走正常交付，4000字节逐段扣除并计算每包首部。
- 第4–7天：区分发出、收到与各端状态，实际发送关闭前的报告；区分同序号重传和新业务请求，连续解析HELLO与BYE，逐个新ACK计算慢开始，保留FlightSize与临时拥塞窗口的区别。
- 第8–9天：请求、响应和304使用具体报文；旧正文、验证器、条件请求、复用或更新连成完整过程，同一图片A与样式B贯穿三个HTTP版本的比较。
- 第10–12天：双向公开份额、长期签名钥、证书链与Finished各有明确用途；恢复说明省掉哪些消息；安全图示展示网站中间步骤和实际资源账目；最后追踪同一URL、网段、SYN、样式请求及监听/连接对象。

复读发现的缩写前置、ETag引号和连接字母重新编号等残留均已读回确认。当前未发现重要的阅读阻断，不再为无关细节扩写。

## 正确性

对照RFC、OWASP与官方接口资料检查本轮改变的协议条件、数值、状态和箭头语义，依据见 [FACT_CHECK.md](FACT_CHECK.md)。重点复查TCP独立序列空间、关闭方向、累计确认、Reno窗口、HTTP队头阻塞和缓存验证、TLS密钥与认证分工、输入边界及Socket对象。

结论限于课件声明的教学条件；不提供正确率百分比，不把经典模型当作所有实现的性能规律。独立复读不证明真实学习者必然学懂；每日90分钟仍是计划预算，本轮没有实测学习耗时。

## 实际验证

1. 两份HTML重建与同步检查通过；全部12课、47个知识点、105个网站知识点有效。46项共享图示共94种情形、360步，专用ARP另有两种6步路线。
2. 实际逐步操作全部共享情形，检查当前内容、末步禁用、退一步与重置；两条ARP路线确认下一跳MAC在回答后揭示。浏览器未发现相关警告或错误。
3. 逐项比较发布基线的知识点、笔记、作答与关联标识；60道自测及答案原文未改变。HTML标记、JS语法、5项状态测试和3项设备范围测试通过。
4. 在隔离页面导入发布版的schema 2测试记录，刷新新版并导出，笔记、答案、自评、收尾勾选、已完成天数及分天用时一致。第3天笔记可打开，前两天仍完成，只开放到第3天。未读取或覆盖学习者真实记录。
5. 检查1280与390像素视口：图示、控件与正文可用，宽图在内部横向滚动；第9–12天没有整页横向溢出。第1、10天交接导出包含设备范围、全部比较情形及TLS恢复步骤。

浏览器验收通过本机HTTP页面进行；产物仍为自包含HTML，但不把本次结果写成file协议实测。测试材料与截图仅存于被忽略的 `.local/`。

## 入口与发布边界

`index.html`仍为study模式，按正式记录逐日解锁；`review.html`开放全部12天并使用隔离检查记录。课程ID、schema、保存键以及计时/记录代码未改。本轮按用户于2026-11-15的授权通过独立分支与PR交付，不直接合并主分支。更新课件前建议在学习电脑导出正式学习记录备份，并继续使用原浏览器和原打开地址。
